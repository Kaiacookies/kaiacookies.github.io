KAIA KOOKIES — SITE AUTONOME

Ce dossier contient une boutique statique indépendante de Shopify.

Fichiers :
- index.html : accueil + catalogue
- panier.html : panier avec quantités et total
- commande.html : formulaire de commande
- app.js : produits, panier et logique
- style.css : identité visuelle basée sur le thème fourni
- hero.jpg / menu-prix.jpg : visuels du thème fourni

Prix : 3,00 € par cookie.
Zone : Lyon.

IMPORTANT : la version livrée gère le panier et prépare les commandes côté navigateur. Elle ne traite pas encore un paiement bancaire réel et n'envoie pas automatiquement la commande à ton téléphone/e-mail, car il faut choisir le moyen de paiement et le canal de réception des commandes. Stripe ou un formulaire backend peuvent être ajoutés ensuite.

MISE EN LIGNE GRATUITE : tu peux héberger ces fichiers sur GitHub Pages, Netlify ou Cloudflare Pages. Aucun Shopify n'est nécessaire.
